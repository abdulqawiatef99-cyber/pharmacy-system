# تحديث البرنامج بحزم إصدار موقّعة

التحديث من شاشة البرنامج يستخدم حزمة الإصدار المنشورة لقناة الجهاز. قناة الصيدلية هي
`main`، وقناة أجهزة التجربة هي `develop`. المثبّت المبني من فرع مراجعة يتبع القناة الرسمية
بعد وصول نسخته إليها.

- جهاز الصيدلية على الإصدار الحالي ينتقل للمحدّث الجديد بزرار «تحديث» نفسه. المشغّل
  الموجود يطبّق الحزمة الموقّعة، والنسخة الجديدة تتحقق من ملفاتها وإثبات التوقيع عند بدء التشغيل.
  بعد التحديث، كل مستخدم بيسجّل دخوله تاني مرة واحدة.
- الزر يعرض تحديثًا بعد التحقق من توقيع الإصدار. الحزمة المقروءة من فلاشة تخضع لنفس التحقق.
  لو التوقيع أو الحزمة ناقصين، التحديث مش هيبدأ.
- يتجهّز التحديث والبرنامج شغال. التغييرات على قاعدة البيانات تتجرّب على نسخة مؤقتة.
  للتطبيق، اختار «دلوقتي» أو «بعد قفل الوردية». البرنامج يتحقق من النسخة الاحتياطية ويرجع
  تلقائيًا لو النسخة الجديدة فشلت في أول تشغيل.

الفحص من سطر الأوامر:

```sh
python manage.py update --check
```

تجهيز حزمة موقّعة من مجلد محلي:

```sh
python manage.py update --prepare --from-bundle BUNDLE_DIR
```

بعد التجهيز حدّد ميعاد التطبيق من شاشة التحديث. احتفظ بملفات الحزمة اللي نزّلها البرنامج
لأن اللانشر بيستخدمها عشان يطابق ملفات النسخة المجهّزة مع توقيع الإصدار.

للرجوع اليدوي لإصدار متوافق من غير استرجاع قاعدة البيانات، استخدم:

```sh
python manage.py update --rollback
```

التحديث اللي غيّر قاعدة البيانات يحتاج استرجاع النسخة الاحتياطية المتوافقة وفق خطة
الاسترجاع. التفاصيل الفنية في [SMART_UPDATE.md](SMART_UPDATE.md).

## مفتاح قراءة اختياري للمستودع الخاص
لو الملف موجود يُستخدم تلقائيًا:
1. github.com ← الصورة الشخصية ← **Settings** ← **Developer settings** ← **Personal access tokens** ← **Fine-grained tokens** ← **Generate new token**.
2. الاسم: `pharmacy-pc-update`. المدة: سنة. **Repository access: Only select repositories** ← `pharmacy-system`.
3. **Permissions ← Repository permissions ← Contents: Read-only** (وسيب الباقي No access).
4. انسخ المفتاح واحفظه في الملف: `C:\Users\<اسم المستخدم>\.pharmacy\github_token.txt` (سطر واحد).
   - الملف **برّا فولدر البرنامج**: مش بيترفع، ومش بيدخل في النسخ الاحتياطية.
   - لو المفتاح اتسرب: امسحه من نفس الصفحة على GitHub واعمل واحد جديد.

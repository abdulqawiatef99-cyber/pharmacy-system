## النسخ الاحتياطي — أربعة أشياء مختلفة
1. **الكود:** commits والفروع على GitHub + أرشيف مصدر مثبت برقم SHA وmanifest وفحص استعادة.
   الأرشيف الحالي ليس Git bundle ولا يحتوي التاريخ الكامل؛ لا ندعي خلاف ذلك.
2. **تاريخ Git:** من جهاز موثوق لديه git مصادق عليه؛ clone mirror مستقل ثم bundle لكل refs
   وgit bundle verify، وحفظ على وسيط خارج الجهاز. لم يُنفذ هنا لعدم توفر Git CLI مصادق عليه.
3. **بيانات الصيدلية:** أدوات backup/verify/restore الموجودة؛ تشمل DB والمرفقات،
   وتحتاج نسخة مشفرة خارج الجهاز وتجربة استعادة دورية. لا تحفظ البيانات/مفتاحها في GitHub.
   لم ألمسها أو أنشئ نسخة منها.
4. **الاستمرار بين الجلسات:** HANDOFF + نتائج اختبارات + SHA + PR + متطلبات/قرارات.
   GitHub يحفظ المصدر؛ ليس بديلًا عن نسخة مستقلة عند فقد الحساب أو حذف المستودع.

الحفظ الخارجي للأرشيف: ينزله المالك إلى جهازه ونسخة ثانية على فلاشة/قرص منفصل.
لا خدمة جديدة مدفوعة. لا تضع PAT أو .env أو venv أو ملفات تشغيل ضمن أرشيف المصدر.
الأرشيف وmanifest يثبتان تطابق النسخة، لا يثبتان خلو الكود من العيوب ولا صحة كل الأرقام ماليًا.

# مصادر البيانات الطبية — ورقة قرار

> الملحق الطبي نفسه بيقول: **ممنوع نكتب كود الجرعات أو التداخلات قبل ما نحدد مصادر البيانات.**
> الورقة دي بتعرض الاختيارات المتاحة عشان صاحب المشروع ياخد القرار. كل اللي هنا اتجمع يوم 2026-10-24.
> **الأسعار مش موجودة لأن معظم المصادر دي مش بتنشرها. لازم نطلب عرض سعر من كل مزوّد.**

## ليه مينفعش نعتمد على الذكاء الاصطناعي أو الذاكرة؟
- نموذج لغوي ممكن يكتب جرعة أو تداخل **غلط بثقة**، ومش هيقولك ده جه منين ولا إمتى اتحدث.
- المسؤولية القانونية: الصيدلي محتاج يعرف المرجع وتاريخه لكل تنبيه بيظهرله.
- الحل: الذكاء الاصطناعي **يشرح** النتيجة بالعربي، لكن **التحقق نفسه** بيتعمل من قاعدة بيانات مرخصة ومتوثقة.

## الاختيارات

### أ. قواعد بيانات تجارية مرخصة (الدقة الأعلى، والأغلى)
| المصدر | بيغطي إيه | ملاحظات |
|---|---|---|
| Lexicomp / Lexidrug (Wolters Kluwer) | جرعات بالغين وأطفال، تعديل حسب الكلى والكبد، تداخلات، حمل ورضاعة | مرجع قياسي في الصيدلة السريرية. ترخيص API للمطورين بعقد |
| Micromedex (Merative) | تداخلات، جرعات، سموم | ترخيص مؤسسي |
| First Databank (FDB) / Medi-Span | مصممة خصيصًا تتدمج جوه برامج الصيدليات (تداخلات، تكرار علاجي، فحص الجرعات) | ده بالظبط نوع المنتج اللي محتاجينه للتكامل، لكن تغطيتها للأسماء التجارية المصرية لازم نتأكد منها |
| DrugBank | تداخلات ومواد فعالة، وفيه API | ترخيص تجاري. الاستخدام الأكاديمي مجاني لكن ممنوع في منتج تجاري |
| BNF / BNFC (MedicinesComplete) | جرعات بريطانية، والأطفال في BNFC | ترخيص |

### ب. مصادر مجانية أو عامة (تغطيتها محدودة)
| المصدر | بيغطي إيه | الحدود |
|---|---|---|
| نشرات المستحضرات الأمريكية (openFDA / DailyMed) | النص الكامل للنشرة الرسمية | نص حر مش منظم. مستحضرات أمريكية مش مصرية. محتاج مراجعة صيدلي لكل معلومة بنستخرجها |
| RxNorm (NLM) | أسماء المواد الفعالة والعلاقات بينها | **مش فيه تداخلات.** المكتبة الطبية الأمريكية وقفت خدمة التداخلات بتاعتها ([DrugBank blog](https://blog.drugbank.com/nih-discontinues-their-drug-interaction-api/)) |
| قائمة ONC للتداخلات عالية الخطورة (Phansalkar et al., 2012) | حوالي 15 تداخل حرج متفق عليها | منشورة علميًا وصغيرة. تنفع كبداية "التداخلات الحرجة بس" بعد ما صيدلي يراجعها |
| قاعدة بيانات الدواء المصرية EDDB (هيئة الدواء) | الأسماء التجارية المسجلة في مصر، والمادة الفعالة، والتركيز، والشكل، وحالة التسجيل ([آلية البحث](https://www.edaegypt.gov.eg/media/ajqiccqc/np-ppma-18-mechanism-of-egyptian-drug-database-eddb-searching-tool.pdf)) | ممتازة عشان **نربط الاسم التجاري المصري بالمادة الفعالة**. لكن البحث فيها محمي بكود تحقق ومفيش API ولا تصدير، **فمش هنسحب منها بيانات أوتوماتيك**. ممكن نطلب البيانات رسميًا من الهيئة |

### ج. قاعدة بيانات بنبنيها إحنا ويراجعها صيدلي
- بنبدأ بنطاق صغير ومحدد، مثلًا أكتر 100 مادة فعالة بتتصرف عندك، ونسجل لكل معلومة المرجع وصفحته وتاريخه **ومين راجعها**.
- مناسبة كمرحلة أولى قبل الترخيص التجاري، **بشرط** إن كل قاعدة تتراجع من صيدلي قبل ما تشتغل.
  (د. عمرو تمراز مذكور في قايمة أفكارك كصاحب فكرة الأداة السريرية، وممكن يكون هو المراجع.)
- النظام هيقول بوضوح "**لا توجد بيانات كافية**" لأي حاجة برا النطاق ده، وعمره ما هيقول إن الحاجة دي آمنة.

## التوصية
1. **دلوقتي (من غير تكلفة):** نبني البنية التحتية لمحرك السلامة (المرحلة 3)، وده من غير أي محتوى طبي.
   وفي نفس الوقت نشتغل على **ربط الأسماء التجارية بالمواد الفعالة** من بيانات E-Stock + مراجعة يدوية + EDDB يدويًا. ده أساس كل حاجة بعده.
2. **المرحلة الأولى السريرية:** اكتشاف **تكرار نفس المادة الفعالة** في نفس الفاتورة. دي محتاجة بس ربط الاسم بالمادة الفعالة، **من غير قاعدة تداخلات**، وقيمتها عالية.
3. **بعدها:** نطلب عروض أسعار من FDB أو Medi-Span أو Lexicomp أو DrugBank، ونختار على حسب التغطية للسوق المصري والسعر.
4. **حاسبة الجرعات:** آخر حاجة، ولأدوية محددة ومُراجعة بس (أدوية الأطفال الشائعة: باراسيتامول، إيبوبروفين، أموكسيسيلين). كل جرعة مسجل معاها مرجعها، ومش هتتفعل قبل مراجعة صيدلي.

# قائمة الصلاحيات النهائية (الجزء 3، تصحيح المالك A)

كل صلاحية بتتفتح أو تتقفل لكل شخص لوحده من شاشة «المستخدمون». النوع (مالك، مدير، صيدلي، مساعد) قالب بيبدأ منه بس.
المالك بيفتح ويقفل أي حاجة لأي حد (ما عدا نفسه: عنده كل حاجة دايمًا). المدير (صلاحية `users.permissions`) بيفتح ويقفل صلاحيات الصيدلي والمساعد،
مش صلاحياته هو ولا صلاحيات مدير تاني، ومابيفتحش حاجة هو نفسه معندوش. إضافة مستخدم وتغيير نوعه وإيقافه للمالك بس (`users.manage`).

القائمة دي متطابقة مع الكود (`app/core/permissions.py`)؛ اختبار `tests/test_permissions_doc.py` بيفشل لو اتغيروا من غير ما الملف يتحدّث.

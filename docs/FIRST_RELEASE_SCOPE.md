## قائمة التنفيذ الثابتة الآن
1. **تم:** تثبيت نطاق النسخة الأولى بهذا الملف، وحفظ الإصلاحات منفصلة. #2–#8 غير مدمجة.
2. **المهمة الحالية:** أداة فحص إصدار معزولة قابلة للتشغيل على Linux وWindows؛ تختبر الموجود وselftest/init/verify بقاعدة مؤقتة، دون تثبيت مكتبات أو تشغيل خادم/طابعة أو لمس الإعدادات الفعلية. ينتهي الباب بتقرير ونتائج فعلية محفوظة؛ التنفيذ على Windows لا يُدّعى قبل حدوثه.
3. **التالي:** نسخة مراجعة موحّدة من التغييرات المحفوظة مع تسوية تداخل API واختبارها؛ فرع مستقل فقط، لا main merge أو نشر. تثبيت SHA المرشح في التسليم.
4. **بوابة Windows:** الفحص المعزول للمصدر المرشح، ثم المُثبّت والبدء والرجوع؛ يتطلب بيئة Windows مصرحًا بها. الجهاز الوحيد للصيدلية ليس متصلًا بنا، ولا تُجرّب عليه بيانات حقيقية.
5. **بوابة البيانات والأجهزة:** استعادة تجريبية، قارئ وطباعة ودرج، ثم يوم بيع تجريبي ومطابقة الأرقام.
6. **قرار المالك:** مراجعة ودمج المعتمد وتحديد إصدار وتشغيل فعلي. لا تغيير E-Stock أو الإنتاج آليًا.

لا نفتح مراجعة أخطاء بلا حدود. عيب مؤكد يهدد المال/الرصيد/العزل/الاستعادة يسجل ويُعالج بمهمة محددة؛ تحسين غير مانع يدخل المتطلبات المستقبلية.

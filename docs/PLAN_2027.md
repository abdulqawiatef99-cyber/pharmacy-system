# الخطة المعتمدة (2026-10-24) — صاحب الصيدلية وافق عليها

## قواعد الشغل
1. التصميم قبل الكود: كل شاشة تتعرض كتصميم تفاعلي وتتعتمد قبل البرمجة.
2. صاحب الصيدلية عمره ما يكتب أمر: تثبيت بملف، تحديث بزرار، نسخ احتياطي أوتوماتيك.
3. كل مرحلة تخلص بحاجة بتتستخدم في الصيدلية فعلًا.
4. مرحلة واحدة في الجلسة، وتترفع على GitHub في آخرها.

## أساس التصميم
- خلفية رمادي فاتح دافي (مش أبيض ناصع)، نص غامق مش أسود، ووضع ليلي.
- ألوان بمعنى ثابت: أحمر = خطأ/ممنوع، أخضر = صح/تم، برتقالي = تنبيه (صلاحية قريبة)، أزرق = معلومة.
- اللون مش لوحده: أيقونة + كلمة دايمًا.
- تباين WCAG 2.2: 4.5:1 للنص العادي، 3:1 للنص الكبير وعناصر الواجهة.
- كيبورد وباركود أولًا، أقل ضغطات، زراير لمس كبيرة على الموبايل، ونفس الزرار في نفس المكان.

## المراحل
0. **التصميم** (من غير كود): نظام الألوان والخطوط + شاشات: الرئيسية، الكاشير (كمبيوتر وموبايل)، كارت الصنف، الشراء، العملاء.
1. **نسيب E-Stock:** كاشير سريع + مرتجع + قفل يومية وخزنة؛ كارت صنف كامل (أسماء الوحدات، المكان، حد الطلب، سعر لكل تشغيلة)؛ شراء يدوي ومن ملفات الموزعين + نواقص + حسابات موردين؛ عملاء وآجل؛ نسخة احتياطية يومية أوتوماتيك + نسخة برّا الجهاز؛ تقارير مبيعات وربح وأصناف. أسبوعين بالتوازي ثم قفل E-Stock.
2. **الموبايل على واي فاي الصيدلية (من غير سيرفر):** بيع، تصوير فاتورة الشراء (قرار تكلفة)، جرد.
3. **الأدوات الذكية:** رواكد من المبيعات الداخلية، تنبيهات صلاحية، مقارنة عروض الموزعين، طلبات المزمن الشهرية، قاعدة عملاء ذكية.
4. **التواصل:** واتساب (تذكير وطلبات)، وموقع/تطبيق باسم الصيدلية للطلب المباشر (من غير طلبات ومن غير عمولة).
5. **السيرفر:** بعد الاستقرار فقط (~325 ج/شهر): رفع، صيدلية تانية، بيع لصيدليات أخرى.

## ملاحظات E-Stock اللي لازم نحلها
تهنيج، مشاكل في الباك أب، مشاكل في التسعير، بطء، ومفيش تحديثات.
